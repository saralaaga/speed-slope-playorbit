About BlockBlast

BlockBlast is a classic block game suitable for all ages. It is extremely easy to learn, but achieving high scores can be very challenging. Drag the generated blocks from each round into the grid.

Categories: Puzzle Games · Arcade Games

How to Play

  1. BlockBlast is a classic block game suitable for all ages
  2. It is extremely easy to learn, but achieving high scores can be very challenging
  3. Drag the generated blocks from each round into the grid

Controls

  • Space — jump / action
  • Drag — move items

Tips & Tricks

  • Work from the corners — they constrain the board the most.
  • Plan two moves ahead before committing.
